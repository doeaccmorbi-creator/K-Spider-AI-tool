🏗️ Architecture — How It Works

VOXAI Pro combines Claude AI (Anthropic) for intelligence, Web Speech API for voice input, and ResponsiveVoice / SpeechSynthesis for voice output. All processing happens in your browser — no data stored on external servers.

Data Flow:
Your Voice 🎙️ → Browser Speech API → Text → Claude AI → Response Text → TTS Voice 🔊
Everything runs in your browser. Conversations stay on your device.

⚡ 3 API Options — Kaunsa Choose Karein?

🟢 Option 1: Groq AI — RECOMMENDED (100% FREE Forever)
Browser → api.groq.com (Groq key browser mein, but FREE daily limit bohot zyada)
✅ Best for public tools — No cost, fast, smart Llama 3.3 70B model
📖 Get key: console.groq.com → API Keys → Create Key
🔵 Option 2: Cloudflare Proxy — Most Secure
Browser → your-worker.workers.dev → api.anthropic.com
✅ API key kabhi browser mein nahi aati — enterprise-grade security
📖 Deploy: dash.cloudflare.com → Workers → worker.js paste karo
🟡 Option 3: Anthropic Direct — $5 Free Credit
Browser → api.anthropic.com (Claude Sonnet 4 — most intelligent)
📖 Get key: console.anthropic.com → API Keys

📦 Worker.js Deploy Kaise Karein — Step by Step

  1. Cloudflare account banao — dash.cloudflare.com pe jaao (FREE plan)
  2. Workers pe jaao → "Workers & Pages" → "Create Application" → "Create Worker"
  3. worker.js paste karo — downloaded file ka pura content copy karke editor mein paste karo
  4. "Save & Deploy" dabao — tumhara URL mil jaayega: https://voxai-proxy.yourname.workers.dev
  5. API Key add karo → Worker Settings → Variables → Add: ANTHROPIC_API_KEY = sk-ant-...
  6. VOXAI Pro mein set karo → ⚙️ Config → Proxy Setup → URL paste karo → Save
✅ Cloudflare Free Plan: 100,000 requests/day — lifetime free for normal usage!
✅ API key browser mein kabhi nahi aayegi
✅ Automatic rate limiting & CORS handling

How to Use VOXAI Pro 2.0

🎙️ Voice Chat

  1. Tap the 🎙️ mic button or type in the text box
  2. Speak or type your message in any language
  3. AI responds — audio auto-plays if volume is on
  4. Use Smart Reply chips for 1-tap responses
  5. Click 📋 Summarize to get conversation summary
  6. Press Ctrl+F or 🔍 to search chat history

📞 AI Call

  1. Select an AI Agent (Nova, Dev, Zara, Chef etc.)
  2. Choose language from dropdown
  3. Press 📞 CALL — speak naturally
  4. Press 📵 END to finish

✨ Generate Text

  1. Select output language
  2. Type prompt or pick Quick Template
  3. Click ✨ Generate
  4. Use 🔊 Speak / 📋 Copy / 💾 Save

📱 Install as App (PWA)

  1. Open in Chrome on Android
  2. Banner appears at bottom → tap Install
  3. OR Chrome menu → "Add to Home Screen"
  4. App works offline after install!

🌐 Proxy Setup (Secure Mode)

  1. Deploy worker.js to Cloudflare (free)
  2. Add your Anthropic API key as environment variable
  3. Go to ⚙️ Config → Proxy Setup
  4. Paste your Worker URL and save

⌨️ Keyboard Shortcuts

  • Ctrl+M — Toggle mic
  • Ctrl+F — Search chat
  • Ctrl+S — Summarize chat
  • Ctrl+E — Export chat
  • Ctrl+1–5 — Switch tabs

💡 Tip: Use Chrome on Android for best mic & voice experience. Maximize media volume!
